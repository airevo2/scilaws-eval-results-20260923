    #   n_D(20 C) ≈ 1.4318
    #   dn/dT ≈ -4.0e-4 / C

    Refractive index of ethylene glycol as a function of wavelength and temperature.

    Standard empirical dispersion/temperature form:
        n(λ, T) = A0 + A1/(λ^2) + A2/(λ^4) + B*(T - 20)

    where λ is in micrometres and T is in °C.

    The coefficients below are representative literature-style values for ethylene glycol
    over the visible/NIR and moderate temperature range. They give a standard closed-form
    approximation for the refractive index.
    """

    T = X[:, 1]

    A0 = 1.4256
    A1 = 0.00643
    A2 = 0.00017
    B = -3.85e-4  # d n / dT near room temperature

    n = A0 + A1 / (lam ** 2) + A2 / (lam ** 4) + B * (T - 20.0)
    return n
