    Predict Voigt-Reuss-Hill bulk modulus K_VRH [GPa].

        K = rho * v_s^2 - 4/3 * G

    However, since only the listed inputs are provided and no shear modulus or
    sound velocity is available, the most common universal closed-form relation
    for bulk modulus from elastic constants is the Voigt-Reuss-Hill average:

        K_VRH = (K_Voigt + K_Reuss) / 2

    With only composition/structure descriptors given, a widely used simple
    closed-form proxy for bulk modulus is the inverse compressibility scaling
    based on density and atomic volume. Here we use the standard empirical

        K ~ A * rho^m * V_a^n

    V_a = X[:, 0]   # angstrom^3 / atom
    M_avg = X[:, 1] # amu

                  np.where(cs == 3, 0.98, # orthorhombic

    # Bulk modulus scales approximately with rho^(5/3) / M^(2/3) * V^(-1/3)

    # Coefficient chosen to keep values in a physically plausible GPa scale.
    K = 0.55 * s * (rho ** (5.0 / 3.0)) * (M_avg ** (-2.0 / 3.0)) * (V_a ** (-1.0 / 3.0)) * 100.0

import numpy as np

def predict(X):
    """
    Predict Voigt-Reuss-Hill bulk modulus from a physically motivated closed-form
    approximation. For polycrystalline solids, the bulk modulus scales with
    density and sound velocity; a simple canonical surrogate is the material
    stiffness scale  ~ rho * v^2. Using only the provided inputs, we use a
    power-law form consistent with elastic scaling:
        K ~ A * rho^alpha * V_a^beta * M_avg^gamma * f(cs)
    with a crystal-system factor f(cs) that mildly increases stiffness for
    higher-symmetry lattices.
    """
    X = np.asarray(X, dtype=float)

    Va = X[:, 0]      # angstrom^3 per atom
    M = X[:, 1]       # amu
    rho = X[:, 2]     # g/cm^3
    cs = X[:, 3]      # crystal system id

    # Map crystal system to a mild symmetry factor.
    # 2 monoclinic, 3 orthorhombic, 4 tetragonal, 5 trigonal, 6 hexagonal, 7 cubic
    sym_factor = np.where(cs == 2, 0.92,
                  np.where(cs == 3, 0.96,
                  np.where(cs == 4, 1.00,
                  np.where(cs == 5, 1.03,
                  np.where(cs == 6, 1.05,
                  np.where(cs == 7, 1.08, 1.00))))))

    # Canonical elastic scaling surrogate (dimensionally fitted to GPa).
    # Heavier density and smaller atomic volume typically imply larger bulk modulus.
    K = 7.5 * (rho ** 1.15) * (M ** 0.05) * (Va ** -0.85) * sym_factor

    return K
