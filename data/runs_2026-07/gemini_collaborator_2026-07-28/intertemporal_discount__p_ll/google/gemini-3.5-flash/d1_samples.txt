    canonical hyperbolic discounting model with a logistic (softmax) choice rule

        X[:, 2] = ll_time_days (t_LL)
        X[:, 3] = delay_diff_days (Δt)

        X[:, 5] = ll_value (V_LL)

    1-D numpy array of probabilities P(LL).

    t_SS = X[:, 1]
    t_LL = X[:, 2]

    # Standard representative parameters from intertemporal choice literature
    k = 0.02  # Daily discount rate
    beta = 2.0  # Softmax inverse temperature (decision sensitivity)

    # Difference in log-discounted values:
    # ln(V_LL_discounted) - ln(V_SS_discounted)

    using the standard hyperbolic discounting model with a logistic choice rule.

    Parameters:
    X : 2-D numpy array where:
        - X[:, 0] = log_amount_ratio (ln(V_LL/V_SS))

    # In log terms, ln(SV_LL / SV_SS) = ln(V_LL / V_SS) - ln(1 + k * t_LL) + ln(1 + k * t_SS)
